## 二、本轮新增（4 项功能 + 3 个 bug）

**功能**
1. 会话双向 —— 关键设计：**同一个 Engine 类的第二个实例**，零新增编排代码
2. 口令 UI + 0600 文件存储（文件在 NEVER_SYNC 里，绝不上云）
3. 三步引导向导（含"我是第一台/我是新机器"的分流）
4. 工作区目录自动创建（新机器上 path 不存在时补建）

**抓到的 bug**
| # | 问题 | 后果 |
|---|---|---|
| 1 | `platformCommand` 展开 Windows 模板时混入 posix 分隔符 | 产出两边都不认的路径 |
| 2 | `passphrase` 改成函数后仍按字符串比较 | `passphraseConfigured` 恒为 true |
| 3 | `routes.mjs` 调用 `api.passphraseFromEnv()` 而 index 没提供 | status 路由静默缺字段 |

第 3 个促成了**路由契约测试**：用假 webServer 真跑每条路由，断言字段齐全、
写路由拒绝 GET。这类"两个文件之间的契约"和之前的 `table.set` 是同一类。

## 四、重要运维结论

**改了 `lib/**` 必须完整重启桌面端。** DSH 热重载只重新导入插件入口
（`index.mjs`），`lib/` 的相对导入留在 ESM 缓存里 —— "磁盘新版、进程旧版"
是常态且重装无效。`npm run verify:install -- --live` 会直接告诉你。
