## 最有复用价值的几个坑

- **多帧 zstd 静默截断**：Node 的 `zstdDecompressSync` 只解第一帧且**不报错**（34.4MB 只出 0.02MB）。
- **YAML 文件走 JSON 合并器**：被判 `invalid JSON` → 每次分叉都 conflict 且远端被隔离 = 永不合并。
- **CRLF 让整份凭据解析为空**：JS 正则 `.` 不匹配 `\r`，而所有解析正则都以 `(.*)$` 收尾。
- **`payload:` 被读成字符串**：真实是 YAML 嵌套映射；DSH 全拒式解析会拒收整份文件 = 凭据全丢。
- **关掉加密开关 = 明文上传**：三态（未声明/已关闭/启用）没分清，导致组关闭时走明文分支。
- **`storageDomain` 的 `stateSchema` 漏键**：未声明的键在 load 时被剥掉 → 每次重启静默重置状态。
- **Windows 上没有 `HOME`**：`${process.env.HOME ?? ''}/.dsh` 会推出 `/.dsh`（当前盘根），且不报错。
